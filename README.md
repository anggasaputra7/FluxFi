# FluxFi

FluxFi is a lightweight DeFi and open finance smart contract project deployed on OPN Testnet.

## Overview

FluxFi demonstrates decentralized financial interaction using EVM-compatible smart contracts.

## Features

* Smart contract deployment
* Open finance experimentation
* Transparent on-chain interaction
* EVM-compatible infrastructure

## Technology Stack

* Solidity
* Remix IDE
* MetaMask
* OPN Testnet

## Deployment

The contract was compiled and deployed successfully.
